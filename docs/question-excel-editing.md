# تعديل الأسئلة باستخدام Excel

من محرر الأسئلة اضغط «تصدير الأسئلة للتعديل»، ثم عدّل ورقة Questions وأعد استيراد الملف في نفس القائمة.

- اترك Question ID كما هو لتعديل السؤال الموجود.
- لإضافة سؤال اترك Question ID فارغًا، واكتب ADD في Action.
- لحذف سؤال اكتب DELETE في Action أو احذف صفه من الملف المُصدّر الجديد. لا تعدّل ورقة Sync IDs.
- راجع أعداد الإضافات والتعديلات والحذف في نافذة التأكيد. الإلغاء لا يغير القائمة.
- بعد التأكيد تُطبّق التغييرات في المحرر ويُستخدم مسار الحفظ المعتاد. راجع حالة الحفظ.

الحذف في مسار الاستيراد متاح للسوبر أدمن وفق الصلاحية الحالية. يُرفض ملف الحذف بالكامل للحسابات الأخرى برسالة واضحة، بدل إظهار نجاح غير حقيقي. أسئلة الامتحان تُحذف باستخدام deletedAt دون حذف سجل السؤال أو إجابات الطلاب من قاعدة البيانات.

الملفات القديمة بدون ورقة Sync IDs لا تحذف الأسئلة الغائبة. القوالب القديمة بدون Question ID تُستخدم للإضافة؛ للتعديل صدّر الملف الجديد أولًا. الأسئلة التي أُضيفت بعد التصدير تبقى موجودة حتى لو لم تكن في الملف.

يدعم القالب MCQ وTRUE_FALSE وMULTI_SELECT وTEXT. الأنواع ذات الاختيارات المركبة أو أكثر من خمسة اختيارات تُعدّل من محرر الأسئلة. الحقول غير الموجودة في القالب، مثل الميتا داتا والارتباط بالاختبار، تُحفظ عند تحديث سؤال موجود.

هذا يخص قوالب الأسئلة والواجبات داخل المحررات؛ ملف استيراد الكورسات والدروس الكامل له مسار مستقل.

## الاختبارات

من مجلد front:

```sh
node --test tests/question-excel-sync.test.cjs tests/question-excel-downloads.test.cjs
```

تختبر الملفات الفعلية بصيغة XLSX. لاختبار الحفظ عبر كود الخادم باستخدام محاكاة قاعدة البيانات، شغّل الأمر التالي من جذر الريبو الرئيسي الذي يحتوي على front وback؛ لا يتصل الاختبار ببيانات الإنتاج:

```sh
node --test tests/question-excel-save.test.cjs
```
